# sincollege-minigame-2

## George Pouria: The Lost Numbers

A small 3D educational mini-game built with Three.js.

### Run locally

From `/home/runner/work/sincollege-minigame-2/sincollege-minigame-2` run:

```bash
python3 -m http.server 8000
```

Then open:

`http://localhost:8000`

### Controls

- **W / A / S / D**: Move
- **Space**: Jump
- **Mouse drag**: Look around
- **Mouse wheel**: Camera distance

### Deploy on GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Set **Source** to **GitHub Actions**.
3. Push to `main` (or run the workflow manually).
4. Open the published site at:

`https://<your-username>.github.io/sincollege-minigame-2/`
